# Понятные лендинги и доступность территорий

Проверено 08.10.2026 на Mac: изолированный scientific repository, Node tests,
Python HTMLParser и локальный стенд в Codex IAB. База — точная опубликованная
версия `f3b7f49de9288ffc83882e857195fa781ca3a0b0`, сохраняющая обучение
пользовательских моделей, кластеризацию и доступ к исследованию.

Обе страницы объясняют задачу простыми словами, расшифровывают ошибки моделей
и отделяют наблюдение от причинного эффекта. Числа таблиц, встроенные данные
графиков, ссылки отчётов, атрибуты форм и маршруты API сверены с исходником.
Frozen JS Атласа, геоданные и лицензия не менялись:
[preservation.json](evidence/landing-coverage-20261008/preservation.json).

## Охват

В опубликованном Атласе — 1896 территорий, 72 региона, январь 2023 — декабрь
2024. Поиск охватывает 2660 ID исторического муниципального словаря из 85
регионов, включая исключённые территории. Он не является современным реестром
и не описывает охват всех продуктов СберИндекса или всех экспериментов Радара.

Не представлены в Атласе: Белгородская область, Брянская область,
Воронежская область, Краснодарский край, Курская область, Республика Бурятия,
Республика Дагестан, Республика Ингушетия, Республика Крым, Ростовская область,
Санкт-Петербург, Севастополь, Чеченская Республика. В остальных регионах тоже
есть исключения. Москва содержит внутригородские единицы; исторические ID
с конечным годом помечены отдельно.

Источники каталога:

- `data/frozen/radar/municipal-dictionary.parquet`, SHA256
  `f25088539a896cdc834d77c8792d0e6ac909d8649b06d65f69215ce12a8eaf4a`;
- `presentation/economic-atlas/demo/atlas-demo-f2098ff9a110.js`, SHA256
  `f2098ff9a110a7e093bbdd6c9a191c22fbcf61888b1f835b545d0f06b4a6227e`;
- `economic-atlas/runs/A14_release_20261005/coverage_exclusions.csv` на базе
  выше: сохранённые причины для 294 исключённых raw ID. Ещё 470 ID словаря
  отсутствуют в исходной выборке расходов этого исследования.

Причины выводятся по сохранённой проверке, без утверждения, что это полный
первоначальный журнал отбора: неполная история расходов, отсутствие ID в
контекстных таблицах или отсутствие в данной исходной выборке.
Готовые графики Радара показывают Орск, Курган и Ишим; остальные эксперименты
используют свои выборки. Пользователь может загрузить другие территории,
если файл соответствует требованиям формы.

## Проверка

Название и регион можно вводить в любом порядке; «е» и «ё» равнозначны.
Есть фильтр региона, число совпадений, очистка, клавиатурный выбор и ссылка
на расходы конкретного ID. При нескольких совпадениях Enter не выбирает
первую территорию. Все 72 региона раскрываются до полного списка доступных
территорий. Обзорные границы OSM 2021 обозначены отдельно.

Семь тестов поиска и каталога прошли без пропусков; семь затронутых JS
прошли проверку синтаксиса:
[журнал](evidence/landing-coverage-20261008/territory-search-tests.log).
В IAB подтверждены два результата «Курганская Шадринск», Enter без
автоматического выбора, выбор стрелкой, исключение Северобайкальска с причинами,
24 доступных и два исключённых ID Курганской области, раскрытие регионов
и прямой переход к расходам Шадринска `1334`. Обе страницы и читаемость
блока охвата просмотрены в браузере.

Новый расчёт пользовательского файла, запрос модели, независимая научная
проверка и проверка современных границ этим прогоном не выполнялись.
Публикация — только `/sberindex-2026/`, под канонической блокировкой,
с побайтной проверкой Storage/CDN и ревью Muse.
