| Требование организаторов | Где в репозитории | Готовность |
|---|---|---|
| GitHub, исходный код и инструкция | README, src, repository-tools | Перенесено; проверки см. reproducibility |
| YAML/JSON конфигурация | config.json, features/spec.yaml, protocol/, run manifests | Есть; исходные планы и параметры фактических прогонов различены |
| Минимум один датасет СберИндекса | data/manifest.json, загрузчик с SHA, manifests | Использован в обоих направлениях |
| Русский методологический отчёт | */METHODOLOGY_RU.md | Промежуточный; окончательные выводы ещё не готовы |
| PDF или интерактивный лендинг | presentation/, опубликованные previews | Шаблоны; экономические итоги ещё не нанесены |
| Кластеризация: метод, граф, сравнение, валидность, интерпретация | A5/A6 runs, лестница A0–A10 | A6 частично; A7–A10 остаются |
| Прогнозирование: сравнение прогнозов и детекторов, обязательная MAE | runs/, лестница R0–R10 | Детекторы сравнили; нет финального paired MAE/Prophet результата |
| Новости и фундаментальные модели | R8 audit, f04 module, research-plan | Аудит готов; проверенный вклад в прогноз ещё не доказан |
| Воспроизводимость и подтверждённые примеры | run manifests, self-check, SHA, receipts | Техническая проверка; окончательный чистый полный повтор до подачи |
| Ссылки с доступом на просмотр | Публичный GitHub и previews | После push проверяется без авторизации |
| Подача формы | Действие владельца | Не выполнена |
