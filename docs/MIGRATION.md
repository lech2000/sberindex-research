# Выделение отдельного репозитория

Дата26.09.2026. Основной источник — joe aiOS2, commit
f7b04954308c8c5b2d56cd9164966c96d18d1775. Экспортированы текущие файлы
 deliverables/sberindex-2026; их исходные SHA и происхождение фиксируются в
 sources/migration-manifest.json. Из Mac добавлены методы ATF и публичный OSM preview,
 отсутствовавшие в joe checkout. Это импортируемый снимок, не переписанная история aiOS2.

Сохраняются: code, протоколы, конфигурации, планы, лестницы, runs, event registry,
аналитическая панель, литература и обзоры, граф/model-lab, состояние агентов,
квитанции кураторов, индексы corpora74–77 и снимки всех действий четырёх дел.
Оригинальные документы20.09 остаются исходными планами; новое README/STATE показывает
что реально измерено. Старый check_scaffold.py остаётся историческим валидатором
каркаса; текущий repository-tools/validate_repository.py проверяет состояние исследований.

Исключены сырые большие выгрузки, секреты, виртуальная среда и неоднозначно лицензированный
HSE геослой. Сырые данные получают загрузчики с SHA. Ссылки в старых документах на
 deliverables/sberindex-2026 относятся к исходному монорепозиторию; в новых инструкциях
корень — этот репозиторий. Расчёты wrapper передают явные пути.

Текущая production копия в aiOS2 не удалена: её продолжают читать инструменты и
research-drive. Этот GitHub — отдельный репозиторий исследований и передачи жюри.
Следующие изменения исследований следует вносить здесь, а платформенную копию
синхронизировать проверенным commit под её deploy lock. Переключение runtime
на новый checkout требует отдельной проверки путей, образов и расписаний.
