## M1. Спектральный счёт кластеров с воздержанием

**Зачем.** Жюри: 15% — сравнение, 15% — индексы валидности, 30% — доверие. Метод отвечает на вопрос «почему k именно такое» и умеет сказать «выраженной кластерной структуры нет». В ATF на отрицательном контроле (быстро перемешивающийся шум) HMM(k=4) и спектральная кластеризация(k=4) «нашли» ровно 4 режима, а HMM с BIC выбрал k=8; этот метод воздержался (m=1). На данных с заложенными R∈{3,4,5} режимами он восстанавливал m=R на 100% прогонов без подачи k.

**Объект.** В ATF — оператор переходов. **Для Атласа применять к графу сходства одного месяца**, а не к переходам во времени (24 точки на ряд — слишком мало, см. «ограничения»).

1. Построить симметричный граф W(t) (кандидат A плана: kNN по cos долей, k∈{10,20,40}).
2. Нормированный оператор случайного блуждания P = D⁻¹W (или симметричный L_sym = I − D^{-1/2} W D^{-1/2}; для P собственные значения λ ≤ 1).
3. Отсортировать собственные значения λ₁=1 ≥ λ₂ ≥ … .
4. **m** = число собственных значений, «прижатых» к 1 (выше порога близости τ_λ); **m=1 означает одну связную массу, т.е. отсутствие разбиения** — это валидный ответ «нет структуры».
5. **sig = gap_to_bulk / bulk_spread**, где gap_to_bulk = λ_m − λ_{m+1}, bulk_spread — разброс «хвоста» (λ_{m+1..}) (например, IQR или std).
6. Кластеры принимаются только при **m ≥ 2 и sig ≥ sig\***.

**Контроль перемешиванием (обязателен).** Тот же граф с перемешанными признаками МО (или configuration-model rewiring с сохранением степеней) → распределение raw_gap_shuffle. Вердикт: REAL_GAP только если raw_gap реального графа выше 95-го перцентиля shuffle. Использовать **сырой разрыв** λ_m − λ_{m+1} (ограничен) для сравнения с shuffle; отношение sig — только для отбора.

**Калибровка sig\*** (как в ATF): синтетика с заложенными R группами (положительный контроль) и граф без групп (отрицательный), та же размерность и плотность, что у реального графа МО. sig\* выбирается строго между max(neg) и min(pos). В ATF получилось 7.3 (neg.max 0 < 7.3 < pos.min 15) — **не переносить число**, пересчитать.

**Уроки, которые стоили нам итераций.**
- Первая версия статистики (z одного разрыва против соседних) дала ложные позитивы на вырожденных хвостах: чинить концептуально (m≥2, gap-to-bulk), а не подкручивая порог.
- Деление на почти нулевой хвост маленькой матрицы даёт «sig≈34 000» — численный артефакт; shuffle-контроль тоже «взрывается». Поэтому финальное сравнение — по сырому разрыву.
- Порог sig **зависит от размера/длины окна**: на коротком окне реальная структура недонасыщена (в ATF sig≈3 на окне 800 против 7.3 на 8000). Калибровать на том же размере графа, на котором применяется.

**Выход в отчёт.** Таблица по месяцам: m, λ₂…λ_{m+2}, sig, raw_gap vs shuffle p95, вердикт; рядом — SW/CH/S_Dbw для k=m и для сетки k. Если m=1 во многих месяцах — это результат, а не ошибка: типология по долям тогда описательная, и это честно сказать.

**Ограничение (важно).** В ATF спектральный разрыв появлялся только когда представление уже было «нарезано» по структуре (§VII: на рынке, поведенческом потоке, CLIP-зрении разрыва не было ни при какой гранулярности). Метод **подтверждает** структуру, заложенную в выбранном пространстве признаков, но не гарантирует её «открытие». Поэтому M1 комбинируется с M4 (абляция пространств).

## M2. Идентичность кластера как области во времени

**Зачем.** План E04: «метки соседних месяцев согласовать по пересечению МО; рождения/исчезновения и split/merge хранить отдельно; совпадение номера ничего не доказывает». В ATF ровно эта задача прошла путь от провалов к рабочему механизму.

**Почему не по составу и не по графу.** Сопоставление по составу (Jaccard членов) ломается при переименовании/дрейфе; структурные инварианты графа слепы на малых кластерах. Рабочий носитель — **геометрия**: кластер = область в пространстве признаков.

**Алгоритм.**
1. Для каждого кластера c месяца t: центр μ_c (среднее по МО) и радиус r_c (например, RMS-расстояние членов до центра). Для кластеров с ≥ ~10 членами можно эллипсоид (центр + ковариация, со shrinkage), для малых — только сфера: на 2–3 точках форма — шум (в ATF переход эллипсоид→сфера поднял самоперекрытие n=2 с 0.04 до 0.69).
2. **Перекрытие** двух областей — коэффициент Бхаттачарии для гауссиан (для сфер — формула с изотропной ковариацией r²I). Значение в [0,1].
3. **Узнавание:** кластер месяца t+1 наследует идентичность кластера месяца t, если overlap ≥ θ_ov **и** он выше второго кандидата на **spec_gap** (страж «близнецов»: два похожих типа не должны сливаться в одну идентичность).
4. **Дрейф:** при узнавании область обновляется (скользящее среднее центра/радиуса) — идентичность та же.
5. **Рождение:** нет кандидата с overlap ≥ θ_ov → новая идентичность.
6. **Спящее состояние (dormant):** идентичность без узнавания в текущем месяце не удаляется, а переходит в хранилище на D месяцев; если позже появляется кластер с достаточным перекрытием — это **возвращение** (re-emergence), фиксируется отдельно от непрерывного продолжения.

**Стартовые пороги ATF:** θ_ov = 0.55, spec_gap = 0.30 (выведены для 512-мерного эмбеддинга). **Пересчитать** для размерности признаков Атласа: калибровка = самоперекрытие кластера со своей бутстреп-подвыборкой (верх) против перекрытия с соседним кластером того же месяца (низ); θ_ov и spec_gap ставятся между распределениями.

**Метрики для отчёта:** доля узнанных переходов; продолжения / рождения / исчезновения / возвращения по месяцам; длительность жизни идентичности; сколько раз сработал страж spec_gap. Рядом — ARI/NMI соседних месяцев (как в плане).

**Ловушка «плеча» (§XV.2).** Если кластеризация месяца t считается на скользящем окне, захватывающем t−1, «выживание» идентичности может быть артефактом того, что окно ещё содержит старые данные. Для заявлений об устойчивости типов: кластеризация каждого месяца — только на данных этого месяца (или окна, не пересекающегося с предыдущим), идентичность — через хранилище M2.

## M3. Мереотопология переходов: split/merge

**Зачем.** Отличить «тип распался на два» (split) и «два типа слились» (merge) от «два типа просто сблизились». Центроидная близость это различить не может.

**Операция — вложение (containment):** кластер A ⊂ B, если > 60% членов A лежат внутри области B (Махаланобис < 2.5 для эллипсоида; для сферы — расстояние до центра < κ·r_B). В ATF на мире part-whole вложение дало F1 0.86–0.91 против 0.58–0.75 у центроидного базиса, а на мире «просто близко» — 0 ложных вложений.

**Правила для Атласа (между t и t+1):**
- **split:** ≥2 кластера t+1 вложены в один кластер t (каждый своей долей), и ни один из них по отдельности не узнан как продолжение с overlap ≥ θ_ov;
- **merge:** один кластер t+1 содержит ≥2 кластера t;
- **близость без вложения** — не событие.

**Контроль:** синтетический мир «part-whole» (кластер t+1 буквально составлен из точек двух кластеров t) и мир «proximity» (кластеры сдвинуты рядом, но не составлены) — метод обязан найти первое и воздержаться во втором. Пороги 60% / 2.5 — установлены, не прогнаны по сетке: сделать чувствительность.

## M4. Двойная дивергенция каналов (дизайн абляции E05 / H1)

**Принцип из ATF (§XI–XII).** Новый уровень структуры строится не пересчётом того же пространства, а **сменой канала отношений**. Центроидный канал давал «плоский» результат там, где канал совместной встречаемости (context) и канал композиции строили уровень (разрыв ×4.4–4.8 и ×5–6 над shuffle).

**Как применить к Атласу.** Каналы-кандидаты плана: A (доли расходов), B (сходство динамики), C (мобильность — только СЗФО). Для каждого канала — синтетический мир, где структура заложена **только в этом канале**.
- Требование: канал строит кластеры на **своём** мире и **воздерживается** (m=1 по M1) на мире другого канала.
- Без второго условия (воздержания) положительный результат канала может быть артефактом (в ATF граф композиции всегда ветвится — и именно проверка воздержания исключила этот артефакт).

Это делает абляцию «доли / динамика / мобильность» доказательной, а не просто таблицей метрик, и прямо отвечает на критерий «почему близость экономическая».

## M5. Биографический L2: группы МО с совместной историей

**Идея.** После M2 у каждого МО есть траектория идентичностей (типов) по месяцам. Матрица совместного присутствия C(i,j) = 1, если МО i и j хотя бы раз одновременно принадлежали одной идентичности (или доля таких месяцев). Спектральный разрыв C (M1) против **перемешивания с сохранением «возраста»** (сохраняются длительности и число смен типа у каждого МО, перемешиваются моменты) показывает, есть ли надтипы траекторий.

**Мощность (ATF §XXI):** детектор слеп при N ≤ 15, пограничен при 25, чист при N ≥ 40 (структура z 5.3–6.4, случай z < 0). У Атласа 2 016 МО с полной историей — впервые детектор в своём режиме. В ATF на 32 объектах получен обоснованный ноль (z = −0.7) — ноль здесь тоже валидный ответ.

**Когда делать:** только после работающего E04; иначе нечего агрегировать.

## M6. Утечки через кодирование

**Урок ATF.** Три «связи» в данных оказались тавтологиями кодирования: канал содержал производное другого канала (пример: бит «плавает» в канале действий был определён как oxygen < 20, и вся связь тело↔действие = 0.725 оказалась артефактом одной строки кода). Скачущий между окнами вердикт был симптомом, а не «вырожденностью данных».

**Чек-лист для Атласа и Радара:**
- доли категорий и log-объём считаются из одних и тех же расходов: при H5 сравнивать не только качество, но и корреляцию признаков с разбиением по построению;
- индикаторы пропусков не должны кодировать сам ответ (например, если скрытые значения связаны с малым размером МО, а размер — ось кластеризации);
- в Радаре: rolling-статистики, лаги, календарь и новости — только с `available_at ≤ origin`; проверять кодом (assert на каждом join), а не описанием;
- любая «сильная связь», меняющая знак/силу между окнами, — сначала искать общий источник в коде признаков.

## N1. Радар: чего не делать

**Спектральное / метастабильное раннее предупреждение на коротких окнах не работает.** ATF, четыре прогона: у метастабильности нет надёжного прокси на коротком окне; разделение «структура против шума» растёт с длиной окна (sig 2.0→5.8 при окнах 500→2500), короткое окно недонасыщено и даёт ложные всплески на бесструктурных шоках. При 24 месячных точках на ряд это заведомо вне рабочего режима. Для H4 оставить план: порог, CUSUM/Page–Hinkley, байесовский онлайн-детектор.

**Состояние сложной модели ≠ режим.** E1 в ATF: внутреннее состояние не кодировало рыночный режим сверх простой σ-статистики (ARI 0.001–0.012 при базисе 0.043) на двух независимых разметках. Вывод для Радара совпадает с H5 плана: каждая сложная модель — против простых бейзлайнов на тех же origins; тюнинг до победы над базисом запрещён.

## N2. Радар: компактность через забывание — только как контроль

В ATF (§IX): при равной способности рождать прототипы и одинаковом surprisal (6.22) модель с забыванием после возврата режима держала 4 прототипа против 10 без забывания (~3×). Ниша широка по τ, усиливается на плавных переходах, **ломается под шумом**. На месячных рядах из 24 точек практической пользы не ждём. Допустимый опыт: синтетический ряд с известным сдвигом «режим 1 → 2 → 1» как положительный контроль для оценки задержки детекторов H4.

## Дисциплина (из ATF, совместимая с планами дел)

- Порог и правило вердикта фиксируются до контакта с тестовыми данными; изменение после просмотра — пометка exploratory.
- Каждый позитив проверяется тем же лезвием, что и ноль: синтетический положительный контроль (метод ловит заложенное) и отрицательный (воздерживается на шуме).
- «Выживание» и «устойчивость» проверять на артефакты окна (M2, ловушка плеча).
- Не менять определение критерия, чтобы результат прошёл (в ATF отклонено явно: сопоставление «через мёртвые кластеры» превратило бы критерий в пустой).
- Единственный формат, стабильно дававший интерпретируемый вердикт в ATF, — held-out предсказание внешней наблюдаемой. Для Атласа это H3 (отложенные независимые экономические показатели), для Радара — rolling-origin MAE.
