# Лендинги СберИндекса

Публичные страницы: `economic-atlas/landing/` и `shock-radar/landing/`.
Результаты синхронизированы с научными страницами 04–05.10.2026, с оговорками
о синтетике, просмотренных окнах, внутренней сети AVI/AVU и неопределённом MQ.

Голографический фон использует 87 региональных геометрий исторического
экспорта OSM 2021, упрощение 12 км и проекцию Albers. Это декорация, число
объектов не описывает актуальный административный реестр. Источник, SHA и
ODbL указаны в `landing-common/DATA_LICENSE.txt`. Повторить:

```bash
python3 presentation/build_holographic_regions.py /path/OSM_russian_boundaries.geojson
```

Чат имеет режимы Атлас/Радар. API `POST /research/sberindex/chat` находится
в aiOS2, опубликованные документы — корпуса 74/75/76. Вход ФиксАР уровня 2
обязателен; cookie и прежние bearer-сессии поддерживаются. История хранится
только в текущей вкладке. Номера источников и квитанция ответа поступают
с сервера. Рабочий граф, дела и инструменты исследователей не доступны.

Backend: `826b974b5` (маршрут и RAG), `fb30f23a7` и `41857864b` (уточнения научных ограничений и тест квитанции), отдельная ветка `codex/sber-landing-rag-prod`.
Документация: aiOS2 `docs/SBERINDEX_LANDING_CHAT.md`. Чат показывает
фактическую модель, включая замены по существующей политике платформы.

Публикуется только префикс `/sberindex-2026/`; весь сайт ФиксАР не копируется.
Изображения результатов лежат в `shock-radar/assets/`. Скрипты не содержат
ключей. Блокировка `deploy_lock.sh` обязательна и для публикации статики.

## Загрузка датасетов и сравнение выпусков — 05.10.2026

Оба чата принимают CSV/XLSX/Parquet до 8 МБ после входа ФиксАР уровня 2.
Запрос с файлом использует `/research/sberindex/analyze`. Модель выбирает
ограниченный JSON-план; статистика, группировки, Pearson и MAE/RMSE
считаются серверным инструментом. Таблица, формула, SHA, профиль качества
и квитанция доступны для скачивания. Файл в KB или дело не сохраняется.

Обновлённые данные сравниваются с read-only исходными расходами СберИндекса
(SHA из `data/frozen/radar/manifest.json`) либо со вторым пользовательским
файлом. Ключи должны быть уникальны; показываются новые, удалённые,
пересмотренные строки, изменения схемы/периода/охвата. Прежний эталон
не меняется. Новый выпуск требует отдельного scientific run и паспорта;
интерфейс не объявляет запуск полного Prophet/детекторного исследования.

Backend: `codex/sber-dataset-chat`, коммиты `cf76c0594`, `0e9a40d54`;
в живом дереве — `551496d4c`, `462ca38fc`, в Git prod — интеграция
`349038bfc4`. Документация aiOS2: `docs/SBERINDEX_DATASET_CHAT.md`.
63 профильных теста прошли; host validator 46/47, прежний warning
OpenAPI tool 403. Sonnet deploy-review: enforce ok после исправлений.

Проверено 05.10.2026 через живые сервисы Incus aios2 на joe: три HTTP200,
среднее синтетического ряда равно4; сверка двух тестовых выпусков выявила
+1/−1/1 изменённую строку; полная исходная панель303126строк совпала по
SHA и ключам, пересмотров0. Это проверка инструмента, новый реальный
выпуск данных пока не использовался. При сбое пояснения MiMo точная
численная таблица возвращается отдельно; такой сбой наблюдался в первом
smoke, два других получили пояснение MiMoPro.

Форма Атласа проверена в опубликованном браузерном чате с существующим
входом: два CSV, ключ `id`, результат +1/−1/1 и MiMoPro; JSON скачан,
SHA квитанции совпал. Публичный гость получает401, CORS —200.
Четыре опубликованных файла сверены по SHA в Storage и CDN.
Проверенная квитанция: [dataset-chat-release-20261005.json](dataset-chat-release-20261005.json).
Полный научный повтор и замена эталонов требуют отдельного сохранённого
входа, паспорта и протокола, не выполняются кнопкой предварительного расчёта.

Устройство и проверка безопасно записаны отдельными документами в KB62 №16530

/sberindex-2026/ при загрузке и при удалении retired-файлов. СберИндекс
публикуется из этого репозитория отдельно под deploy_lock. Регрессионный
прогон с настоящим shell publisher воспроизвёл потерю страницы до правки
