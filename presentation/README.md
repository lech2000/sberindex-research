# Лендинги СберИндекса

Публичные страницы: `economic-atlas/landing/` и `shock-radar/landing/`.
Результаты синхронизированы с научными страницами 04–05.10.2026, с оговорками
о синтетике, просмотренных окнах, внутренней сети AVI/AVU и неопределённом MQ.

Голографический фон использует 87 региональных геометрий исторического
экспорта OSM 2021, упрощение 12 км и проекцию Albers. Это декорация, число
объектов не описывает актуальный административный реестр. Источник, SHA и
ODbL указаны в `landing-common/DATA_LICENSE.txt`. Повторить:

```bash
python3 presentation/build_holographic_regions.py /path/OSM_russian_boundaries.geojson
```

Чат имеет режимы Атлас/Радар. API `POST /research/sberindex/chat` находится
в aiOS2, опубликованные документы — корпуса 74/75/76. Вход ФиксАР уровня 2
обязателен; cookie и прежние bearer-сессии поддерживаются. История хранится
только в текущей вкладке. Номера источников и квитанция ответа поступают
с сервера. Рабочий граф, дела и инструменты исследователей не доступны.

Backend-коммит: `826b974b5`, отдельная ветка `codex/sber-landing-rag-prod`.
Документация: aiOS2 `docs/SBERINDEX_LANDING_CHAT.md`. Чат показывает
фактическую модель, включая замены по существующей политике платформы.

Публикуется только префикс `/sberindex-2026/`; весь сайт ФиксАР не копируется.
Изображения результатов лежат в `shock-radar/assets/`. Скрипты не содержат
ключей. Блокировка `deploy_lock.sh` обязательна и для публикации статики.
