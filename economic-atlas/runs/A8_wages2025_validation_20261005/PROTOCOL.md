# A8 — внешняя проверка групп Атласа на зарплатах и занятости 2025 года: ПРОТОКОЛ (05.10.2026)

Протокол записан до расчёта по группам. SHA-256 этого файла фиксируется в `provenance.json` прогона; расчёт выполняется один раз, правки кода после
просмотра результатов допустимы только как исправление ошибки с записью в README и повтором всего прогона без смены критериев.

## Вопрос

Добавляют ли группы Атласа экономическую информацию о зарплате и занятости **2025 года** сверх географии, размера и типа МО?
Уровни и изменения проверяются отдельно. Это проверка одного свойства групп; устойчивость идентичностей и «рождение новых типов» ею не проверяются.

## Замороженное разбиение

Бинарная метка архивного прогона A6_v2 в декабре 2024 (`economic-atlas/runs/A6_v2/assignments.parquet`, месяц 2024-12, `label`): `G = 1`, если `label == 1`, иначе 0.
Разбиение построено по данным расходов до декабря 2024 включительно (прогон 26.09.2026), то есть до появления данных 2025 года в наших руках (загрузка 05.10.2026).
Других разбиений в основном анализе нет. Вторичная проверка (не основная): тот же анализ с меткой, пересчитанной на сетке этого репозитория (`z2023`, k-means K = 2, декабрь 2024, зерно 20261004; идентификатор группы выбран так, что `G = 1` — группа с большим средним ln населения).

## Исходы (Tochno/БДМО v20260928, МО верхнего уровня, «Всего», январь–декабрь)

Зарплата `Y48423007` (среднемесячная, организации без малого бизнеса) и занятость `Y48423005` (среднесписочная, организации без малого бизнеса).
Для каждого индикатора: `L25 = ln v2025`, `lag = ln v2024`, `D25 = ln v2025 − ln v2024`.

## Выборка

Панельные МО (1896) с: `year_to == 9999` в справочнике; значения индикатора за 2023, 2024 и 2025 положительные и непустые; `oktmo_history` в Tochno не содержит «Объединение» и «Присоединение»
(границы менялись). Ключ: первые 8 цифр ОКТМО справочника = `oktmo` Tochno. Размер выборки фиксируется в результате; исключения перечисляются по причинам.

## Контроли

Фиксированные эффекты региона (`region_code`); `lat`, `lon`, `lat²`, `lon²`, `lat·lon` (центр МО из справочника); `ln` населения 2024 (Data Sense, строка age = «Всего»);
тип МО (справочник, фиктивные переменные); `ln` индекса доступности рынков (`1_market_access`).

## Спецификации (для каждого индикатора)

* **S1 уровни:** `L25 ~ контроли + G`.
* **S2 уровни с прошлогодним значением:** `L25 ~ контроли + lag + G` (то же, что рост с контролем уровня).
* **S3 изменения:** `D25 ~ контроли + G`.

Оценки OLS. Для коэффициента при `G`: 95% интервал бутстрэпом по регионам (1000 повторов, регионы с возвращением, зерно 20261005); p-значение перестановкой `G` внутри региона (2000 перестановок);
прирост информации: ΔR² (скорректированный) и снижение MSE при 10-кратной перекрёстной проверке, повторённой 5 раз (зёрна 20261005–20261009), модель с `G` против модели без `G`.

## Основные проверки и критерии

Основных проверок четыре: зарплата S1, зарплата S3, занятость S1, занятость S3; поправка Холма на четыре. S2 — диагностика (уровень сверх прошлого уровня) и в число основных не входит.

* **Положительный результат по свойству «изменения»:** интервал для `G` в зарплате S3 не содержит 0 **и** скорректированное по Холму p < 0,05 **и** снижение MSE в перекрёстной проверке положительно. Аналогично для занятости.
* **Положительный результат по свойству «уровни»:** то же для S1. Положительный результат только в S1 и отрицательный в S2 и S3 трактуется как «группы отражают уровень, сложившийся до 2025 года», а не как информацию о 2025 году.
* **Отрицательный результат:** интервал содержит 0 или снижение MSE не положительно. Он фиксируется в итоговом тексте как результат, настройки после него не подбираются.
* Размер эффекта сообщается всегда; «значимо» не заменяет «важно».

## Контроль метода на уже изученном 2024 годе

Те же S1–S3 с исходами 2024 (`L24`, `lag = ln v2023`, `D24`): воспроизводит ли метод ранее найденное (KB75 №14365: различие уровней зарплат сохраняется после контроля региона и населения; прирост после учёта прошлогодней зарплаты исчезает).
Это проверка конвейера, а не новое подтверждение; в число основных не входит.

## Что не заявляется

Причинность, экономические типы, переносимость на другие годы, историческая работа в реальном времени (дата публикации значений неизвестна). Группы — бинарное разбиение структуры расходов одного месяца.
Размер теста ограничен числом МО в регионах (кластеризация по регионам), а не числом месяцев.
