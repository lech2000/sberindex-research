# Проспективный протокол новых расчётов — 05.10.2026

Статус: зафиксирован до расчёта этого прогона. Это локальная предрегистрация с SHA-256 и отметкой времени, без независимого внешнего timestamp.
Известные до протокола результаты: A5; A7 network audit k=5 (AVI 0.878/0.208); A7 stories; весь results.json A8 (четыре отрицательные основные проверки); существующий локальный A7 S_Dbw. Новые результаты A9–A12 ещё не просмотрены. Это расширение описательного анализа имеющейся панели, а не новый независимый тест исходов 2025.

Входы: только существующая полная панель 1896 МО, 24 месяца 2023–2024; A5 features/assignments/geo edges; FROZEN v1 features/spec.yaml. Маски строго одинаковы и сортируются по territory_id; любое расхождение SHA или ключей прекращает расчёт. Нули и пропуски не импутируются. Данные 2025 не читаются расчётным кодом.

Семена: 20261005..20261009 для A10; основной seed 20261005. BLAS/OMP threads=1. Зависимости и SHA всех исполняемых модулей записываются. Исправления реализации без смены спецификации отражаются в execution log; изменения критериев после результатов получают новую версию протокола и метку post hoc. Результаты не используются для выбора сетей/K/порогов.

## A11: индексы и отрицательные случаи

Feature metrics SW (полный точный Euclidean silhouette), CH, DB для 6×3 основных разбиений primary seed и Louvain natural. Все 5 seed feature metrics отдельно; основная таблица заранее выбранного seed. AVI/AVU/ANUI/Q и random_partition_null(B=300,seed20261005) импортируются из network_icvi.py для каждого основного разбиения на всех12 сетях A5. Основная сеть k7 union Gaussian; не выбирать её post hoc. Число групп, максимум доли и число групп без рёбер сохраняются. MQ = SPEC_UNRESOLVED (status/string), не заменять Q. z — стандартизованное отклонение от permutation null, не экономическая валидность и не автоматически p-value; sd=0 => null+reason.

S_Dbw: новая собственная реализация по Halkidi/Vazirgiannis2001 DOI10.1109/ICDM.2001.989517, section3 equations1–5; radius=sqrt(sum(norm(population variance vector)))/K; Scat=mean(norm(cluster variance))/norm(global variance). Density closed Euclidean ball <=radius. Для пары i,j все counts на Ci∪Cj; Dens_bw = mean over unordered pairs [midpoint count/max(centre counts)]. Own-cluster centre domain только отдельная sensitivity. Это выбранная конвенция, не обещание совпадения разных реализаций. Нулевой density denominator => null+NA_ZERO_DENSITY_DENOMINATOR, без epsilon. K<2, K>=n, отсутствующие/нечисловые метки или признаки, zero global variance => неприменимость с reason. Пустые заявленные группы => ошибка; одиночные группы остаются и отмечаются. Проверка вручную на6 точках, label/node permutation, разделённые блобы vs fixed random balanced labels. Общая монотонность по K/расстоянию не предполагается: тест универсальной монотонности из задания научно не обоснован.

Cross-year secondary: annual2023 labels на annual2024 graph и наоборот для основной конфигурации k7 union Gaussian и reverse same-year controls; feature metrics у разбиения в его собственном окне. Парный AVI difference same-minus-cross. Это ослабляет общий same-window контур, но не создаёт независимый источник данных; временная автокорреляция/общая 2023 нормировка остаются.
AVI null ≈1/K только для равных групп при случайной перестановке; для несбалансированных размеров показывать эмпирический null. AVU=1 для K2 только при ненулевом межгрупповом ребре, для K3 не универсальная константа. Кластеры с гигантом отдельно от качества.
