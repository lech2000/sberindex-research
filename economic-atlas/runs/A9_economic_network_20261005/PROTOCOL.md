# Проспективный протокол новых расчётов — 05.10.2026

Статус: зафиксирован до расчёта этого прогона. Это локальная предрегистрация с SHA-256 и отметкой времени, без независимого внешнего timestamp.
Известные до протокола результаты: A5; A7 network audit k=5 (AVI 0.878/0.208); A7 stories; весь results.json A8 (четыре отрицательные основные проверки); существующий локальный A7 S_Dbw. Новые результаты A9–A12 ещё не просмотрены. Это расширение описательного анализа имеющейся панели, а не новый независимый тест исходов 2025.

Входы: только существующая полная панель 1896 МО, 24 месяца 2023–2024; A5 features/assignments/geo edges; FROZEN v1 features/spec.yaml. Маски строго одинаковы и сортируются по territory_id; любое расхождение SHA или ключей прекращает расчёт. Нули и пропуски не импутируются. Данные 2025 не читаются расчётным кодом.

Семена: 20261005..20261009 для A10; основной seed 20261005. BLAS/OMP threads=1. Зависимости и SHA всех исполняемых модулей записываются. Исправления реализации без смены спецификации отражаются в execution log; изменения критериев после результатов получают новую версию протокола и метку post hoc. Результаты не используются для выбора сетей/K/порогов.

## A9: 12 определений × 3 окна

Окна: A5 (готовые z пяти средних долей 2023–2024); annual2023 и annual2024 (среднее помесячных z по соответствующим 12 месяцам, стандартизация pooled2023 из A6). Разные масштабы окон явно указываются, A5 и годовые z не выдаются за одинаковую стандартизацию.
kNN k=5,7,10; union или mutual; binary или Gaussian exp(-d²/(2 sigma²)), sigma = медиана расстояний всех направленных k соседей данного окна. Расстояние евклидово. Каждый узел исключается из своих соседей по ID, а не по месту в выдаче; при равных расстояниях сортировка (distance, territory_id). sigma=0 => ошибка для Gaussian. Рёбра только src<dst, без дублей/петель; isolated nodes сохраняются отдельным nodes.parquet.

Для каждой сети: n_nodes/edges/components/isolates; degree quantiles и histogram; overlap = |economic edges ∩ A5 geographic edges| / |economic edges| (географическая сеть из A5, k_geo=8). temporal Jaccard на идентичных ID между annual2023/2024; веса не входят в Jaccard.
Louvain resolution=1, seed20261005, NetworkX. ARI(k5,k10) отдельно для каждого окна и пары mutual/union × binary/Gaussian. Устойчиво по определению ребра при ARI>=0.5; отрицательные исходы с тем же весом в README. Единое среднее не вычисляется для сокрытия провалов.
Основная сеть A10: A5 k7 union Gaussian (центр заданной сетки, зафиксировано до расчёта); все12 сети входят в A11 sensitivity. Граф нельзя выбирать по связности или score.
