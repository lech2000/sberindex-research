# A7.S1 — S_Dbw на сохранённых разбиениях A5

Выполнено и проверено 04.10.2026 на Mac: исходные A5 Parquet/JSON, SHA,
семь научных контрольных проверок и независимый скалярный пересчёт.
Статус **COMPUTED_DESCRIPTIVE**, полные ворота A7 и экономическая валидность
не пройдены. Это оценка пяти сохранённых разбиений на общей маске **1896 МО**,
а не новое обучение или подбор параметров.

Основной результат: индекс конечен для трёх схем и математически не определён
для двух при зафиксированной формуле. У Louvain нулевой знаменатель во всех
528 парах; у spectral a0 — у пары малых групп размером 2 и 7. Эти NA нельзя
заменять нулём, удалять из среднего или скрывать добавлением epsilon.

## Первоисточник и точная версия

[Halkidi, Vazirgiannis (2001), Clustering Validity Assessment](https://doi.org/10.1109/ICDM.2001.989517),
раздел 3, формулы 1–5, PDF страница 3. Полный авторский текст прочитан через
ResearchGate; запись радиуса визуально сверена с
[авторским tutorial PKDD2002](https://www.cs.helsinki.fi/events/ecmlpkdd/pdf/halkidi-2.pdf),
PDF страницы 69–70, определение дисперсии — страница 71. SHA скачанных
слайдов в [protocol.json](protocol.json); PDF целиком здесь не переиздаётся.

Для группы C_i: v_i — среднее, sigma_i — вектор покоординатных дисперсий
с делителем n_i (ddof=0); ||sigma_i|| — евклидова норма этого вектора.
Scat = mean_i(||sigma_i||) / ||sigma_X||.
Радиус r = sqrt(sum_i(||sigma_i||)) / K. Делитель K расположен **вне корня**.
Плотность — число точек в замкнутом евклидовом шаре расстояния <=r.

Основная договорённость: для каждой пары i,j точки плотности и у середины,
и у обоих центров берутся из C_i union C_j — буквальная общая область
суммирования формулы 2. Dens_bw — среднее по неупорядоченным парам
density(midpoint) / max(density(v_i), density(v_j)); это равно двойной
сумме по упорядоченным парам, делённой на K*(K−1). S_Dbw = Scat + Dens_bw.
Не используется вариация S_Dbw* или CDbw; меньшая величина предпочтительна
только в рамках объявленной конвенции.

Альтернативная конвенция считает плотность каждого центра по собственной
группе (числитель сохраняет union). Она заранее включена как чувствительность,
не выбрана по лучшему результату: a1 **0,672929** вместо **0,661501**;
у остальных четырёх результаты/NA совпадают. Таблица и все парные счётчики
сохранены, чтобы неоднозначность области density не была скрыта.

Все singleton оставлены и отмечены; их дисперсия нулевая по определению.
Нефинитные значения, пропущенные метки, нулевая общая дисперсия, K=1 и K=n
отклоняются. При нулевом знаменателе любой пары Dens_bw/S_Dbw = null / NA;
Scat сохраняется. Спецификация не утверждает универсальную пригодность
центроидного индекса для произвольной географической формы групп.

## Проверка

[Независимый аудит](independent-audit.json): ручной одномерный результат 2/77,
совпадающие группы с различимыми конвенциями плотности, NA при нулевом
знаменателе, singleton, отказ при пропусках/вырождении, инвариантность
перестановки/меток/сдвига/общего масштаба, четыре синтетических seed.
На реальных назначениях обе конвенции независимо пересчитаны скалярными
циклами и math.fsum: **1136 парных наборов плотности совпали точно**,
Scat/radius/Dens_bw с относительным допуском 1e−12.

Первый запуск прервался до записи результатов: контрольная DB у spectral a1
отличалась от A5 на 6,03e−9 в текущем численном окружении. Исходный протокол
сохранён как [protocol-v1-aborted.json](protocol-v1-aborted.json); v2 явно
зафиксировал допуски воспроизведения старых диагностик. Формула, маска,
конвенции и параметры S_Dbw не изменены. Отклонения всех SW/CH/DB записаны
в metrics; DB здесь дополнительная диагностика, а не индекс жюри.

```bash
  --protocol economic-atlas/runs/A7_SDbw_20261004/protocol.json \
  --outdir output/reproduced/A7_SDbw

  economic-atlas/runs/A5 output/reproduced/A7_SDbw
```

совпадение масок. Расчёт не требует сети, API, LLM, GPU или повторной
кластеризации. [Metrics](metrics.json), [CSV](validity.csv),
[SHA артефактов](artifact-manifest.json).

формулой NA; AVI/AVU/MQ остаются **SPEC_UNRESOLVED**. Отсутствующая формула
не является математической неприменимостью. Общий A7 остаётся открытым.
