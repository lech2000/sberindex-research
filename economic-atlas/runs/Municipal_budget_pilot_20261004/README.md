набора организатора, не среднегодовое население. «Налоговые + неналоговые» —
название измеренной группы доходов; показатель не назван юридическими «собственными доходами».
Отрицательный дефицит означает профицит. Номинальные суммы не дефлированы.

не удаляется: естественный ключ включает администратора. Kurgan 2024 использует
верхние группы доходов по администраторам; Kurgan 2023 — leaf-only строки с точной сверкой итога.
Функции Орска/Ишима собраны только из верхних разделов; сумма разделов равна расходам.
Функции Кургана и структура доходов Тюмени остаются NULL: иерархию их приложений не угадывали.

с недоверенной в этом контуре цепочкой, старый pravo-host не разрешается;
tyumendoc: bare-host 403, www-host hostname mismatch. Защита TLS не отключалась.
Новости и проекты найденных решений не подставлены вместо утверждённого отчёта.
