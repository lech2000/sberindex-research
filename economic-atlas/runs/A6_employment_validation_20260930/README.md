# A6: независимая проверка по муниципальной занятости, 30.09.2026

Протокол [`PROTOCOL.md`](PROTOCOL.md) зафиксирован в коммитах `e6ba568` и
`f7e84e1` **до** расчёта. Точный входной SHA, версии Python/библиотек и seed
записаны в `manifest.json`; результат — в `metrics.json` и
`coverage_by_label.csv`. Рассчитывающий код:
`economic-atlas/src/a6_employment_validation.py`.

Панель декабря 2024 содержит 1 896 МО. Действующий в 2023–2024 годах
кроссволк имеется для 1 586; у 310 его нет. Ещё 171 из этих 1 586 не имеет
годового значения занятости **за оба года** при выбранном определении.
Итоговая полная выборка — **1 415 МО (74,6%)** из 67 регионов: 931 в метке 0
и 484 в метке 1. Пропуски не подменялись нулями; старыми ОКТМО и поиском по
названию выборка не расширялась.

Занятость здесь означает среднесписочное число работников организаций без
субъектов малого предпринимательства, а не всех занятых жителей. Медиана
занятости 2024: 3 074 для метки 0 и 14 832 для метки 1; медиана отношения
E24/E23: 0,9835 и 1,0027 соответственно. После контроля `log(E23)`,
`log(P24)` и региона описательный коэффициент метки 1 в `log(E24)` —
**+1,64%**, региональный bootstrap 95%: **+0,29…+3,03%**. Это ассоциация,
не причинное влияние группы. Панель, метки и гипотеза уже изучались до
фиксации протокола, поэтому интервал не является подтверждающим тестом.

В архивном декабре **все 484** покрытые МО метки 1 имеют
`status=ambiguous`/пустой `identity_id`; у метки 0 все 931 покрытых МО имеют
одну распознанную идентичность. Следовательно, между *устойчивыми
идентичностями* сравнивать нечего: основной контраст `NA`, не нулевая
разница. Этот результат не подтверждает экономические биографии
идентичностей и не закрывает A6. Следующий независимый шаг — проверить
синтетические положительные/отрицательные события с известными истинными
метками и отдельно разрешить неоднозначность идентичности без подбора порога
по занятости. Для 310 исключённых МО нужен датированный официальный
кроссволк, а не правдоподобное совпадение названий.

Воспроизведение из корня репозитория (пути к файлам СберИндекса заменить на
локальные копии с SHA из `manifest.json`):

```bash
python3 economic-atlas/src/a6_employment_validation.py \
  --assignments economic-atlas/runs/A6_v2/assignments.parquet \

```
