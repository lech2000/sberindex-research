# Уточнение AVU — 05.10.2026 (пояснение после просмотра таблицы)

В симметричной неотрицательной сети при K=3 обозначим веса между тремя группами a,b,c. Для каждой пары знаменатель out_k+in_l−S_kl равен a+b+c. Если есть хотя бы одно межгрупповое ребро, AVU=2(a+b+c)/(3(a+b+c))=2/3. При K=2 и наличии межгруппового ребра AVU=1. Если межгрупповых рёбер вовсе нет, zero-denominator convention даёт AVU=0. При K=1 также0.

Поэтому исходное задание правильно указывает отсутствие различающей способности AVU при малых K; ему не хватало условия ненулевого межгруппового веса. Ранее в доработке написано «для K3 не универсальная константа»: формально это верно с учётом zero-edge exception, но для чтения основных строк надо использовать точное условное утверждение выше. Все K3 строки основной таблицы имеют AVU=2/3 и не различаются этим индексом.

Это алгебраическое уточнение после результатов, не изменение формулы/порогов/маски и не выбор по score. Числа не менялись. Проверка: отдельный тест на взвешенном графе9 узлов с3 группами и на том же графе с удалёнными межгрупповыми рёбрами. Использована существующая network_icvi.avu, код индекса не менялся.
