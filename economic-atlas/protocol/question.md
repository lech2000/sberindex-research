# Исследовательский вопрос Atlas — A0

**Исследовательский вопрос.** Можно ли по структуре средних безналичных расходов жителей и показателю покупательской мобильности выделить устойчивые типы локальных экономик муниципальных образований, проследить их динамику по месяцам и объяснить изменения конкретными признаками?

**Единица анализа.** Муниципальное образование (МО), идентифицированное по `territory_id` из набора СберИндекса. Кандидатов — 1 896; фактическая полная панель подтверждается после сверки идентификаторов и покрытия по месяцам (A1).

**Период.** Январь 2023 — декабрь 2024, 24 месяца, месячная частота. Подтверждено: `historical_spending` содержит ровно 24 записи на один `territory_id` × категорию (observed, source: data_catalog).

**Показатели и их ограничения.**
- *Расходы:* средние безналичные расходы жителей по 6 категориям (Продовольствие, Здоровье, Маркетплейсы и др.). Единица — руб./мес. Не представляют всё потребление: наличные, карты других банков, корпоративные траты не учитываются. Для territory_id=1, Продовольствие: 7 692 → 8 259 → 8 873 руб. за первые три месяца (observed).
- *Мобильность:* среднее расстояние поездок жителей в километрах. Доступна для 297 МО СЗФО. Не является матрицей потоков МО→МО; нельзя строить граф связности между муниципалитетами на её основе. Используется как дополнительный признак с α-смешиванием: A = α·A_spend + (1−α)·A_mobility, α ∈ {0, 0.5, 1} (source: corpus 75).

**Практический сценарий.** Пользователь выбирает МО и месяц → видит профиль кластера, экономически похожие территории, признаки сходства, факт перехода между кластерами и устойчивость назначения. Прикладное применение — поиск сопоставимых территорий для анализа спроса и обоснования локальных решений.

**Матрица: критерий конкурса → доказательство.**

| Вес | Критерий | Готовим |
|---|---|---|
| 15% | Понятность подхода | Одностраничное объяснение: данные → признаки → кластеры → изменения |
| 15% | Устройство сети и признаков | Формулы, единицы, нормализация, абляция способов связи |
| 15% | Сравнение | ≥3 семейства (k-means, Leiden/Louvain, spectral) при общей выборке |
| 15% | Индексы валидности | SW, CH, S_Dbw, AVI, AVU, MQ — рассчитаны или объяснена неприменимость |
| 30% | Экономическое объяснение | Профили типов, независимая проверка, 3–5 примеров, воспроизведение |
| 10% | Визуализация | Карта, профили, лента переходов с исходными значениями |

**Неподдерживаемые причинные утверждения.** Кластеризация не доказывает, что изменение структуры расходов вызвано конкретной политикой, миграцией, инфраструктурным проектом или новостным событием. Выделенные переходы — статистические паттерны, а не причинно-следственные связи.
