# Атлас — сетевые индексы AVI, AVU, ANUI и модулярность: определения и нюансы (04.10.2026)

Статус: реализация `economic-atlas/src/network_icvi.py`, тесты `tests/test_atlas_network_icvi.py` (24 проходят, 1 с эталоном при `SBERINDEX_PATTERN_REF`).
Не научный результат: инструмент измерения. Закрывает пробел «определения AVI/AVU нужны» (A7); определение MQ остаётся открытым.

## Определения (S_kl = Σ_{i∈k, j∈l} A_ij; A симметрична, неотрицательна, нули на диагонали)

- AVI = (1/K) Σ_k S_kk / Σ_l S_kl — больше лучше, ∈ [0, 1].
- U_kl = S_kl / (out_k + in_l − S_kl); AVU = (1/K) Σ_k Σ_{l≠k} U_kl — меньше лучше.
- ANUI = 1 / (AVU + 1/AVI) — больше лучше.
- Модулярность Ньюмана (взвешенная): Q = Σ_k [S_kk/2m − (d_k/2m)²].

Источники: эталон Shalileh, github.com/Sorooshi/Pattern, `metrics/clustering_metrics.py` (коммит e5ff50b, GPL-3.0; код не переносился);
quizzes1/sberindex ссылается на статью «Defining quality metrics for graph clustering evaluation», Expert Systems with Applications 71 (2017) 1–17 — саму статью мы не открывали.
Сверка: AVI, AVU, ANUI и модулярность совпали с эталоном на 20 случайных взвешенных графах (разное K), модулярность — с networkx; значения на маленьком графе посчитаны вручную.

## Нюансы, которые меняют интерпретацию

1. **AVU константа при K = 2 и K = 3** на любой неориентированной сети: при K = 2 AVU = 1, при K = 3 AVU = 2/3 (знаменатель каждой пары равен S_12 + S_13 + S_23). Таблицы quizzes1 это показывают: AVU 1,000 при k = 2 и 0,667 при k = 3 у всех методов.
   Атлас выбирает K = 2, поэтому AVU там ничего не измеряет; приводить в таблице, но не интерпретировать.
2. **AVU не мера силы разделения.** При равных связях между всеми парами кластеров AVU = (K−1)/(2K−3) независимо от того, слабы эти связи или сильны. AVU показывает, насколько связи кластера сосредоточены на одном соседе («кандидат на слияние»); выбирать по нему число групп нельзя, читать — вместе с AVI и модулярностью.
3. **AVI не нормирован на K** и естественно падает с ростом K (у quizzes1 вопрос о нормировке к жюри остаётся открытым).
4. **Соглашения как у эталона:** кластер без рёбер даёт I_k = 0 (число таких кластеров возвращается в `clusters_without_edges`); пара с нулевым знаменателем в AVU даёт 0.
5. **MQ не установлен.** В условиях конкурса указано «MQ»; найденные материалы не раскрывают определение. Как минимум два кандидата: модулярность Ньюмана и «Modularization Quality» (Mancoridis и др.) — разные величины. Пока организатор не ответил: писать «MQ: SPEC_UNRESOLVED», модулярность показывать под своим именем (`modularity_newman`). В эталоне Shalileh есть `modularity` и `density_modularity`, величины «MQ» нет.

## Что это означает для Атласа

- Нужна сеть «экономическая близость» (узлы МО, рёбра по близости экономических признаков, последовательность по времени): сетевая структура 15% и ICVI 15% по условиям конкурса. В Атласе сейчас граф географический (E02 Louvain), и AVI/AVU/modularity считать не на чем.
  Образец у quizzes1: только экономика (α = 1), гауссов вес, kNN k = 7 + остовное дерево; признаки сети по умолчанию — ВМП на душу, инвестиции на душу, индекс Херфиндаля, плотность, доля старших возрастов.
- Для динамики полезна пулированная кластеризация по всем годам (метки согласованы по построению) как контрольная линия для M2, чья идентичность зависит от порогов (неоднозначных строк 1324 / 4438 / 36024 при порогах ×0,75 / 1 / 1,25). Нормировка — по всей панели: при нормировке по каждому году переходы между кластерами становятся артефактом нормировки.
- S_Dbw у quizzes1 монотонно убывает с k и выбирает k = 9–10; число групп им одним не выбирать.
