# Радар потребительских сдвигов

Радар исследует прогнозирование муниципальных расходов и обнаружение изменений. Он сравнивает простые сезонные ориентиры с другими моделями на одинаковых строках и показывает, как форма сдвига влияет на работу детекторов.

MAE — средняя абсолютная ошибка, меньше означает лучше. Национальный пилот относится к июлю–декабрю 2024, а выигрыш не переносится на все категории: маркетплейсы проигрывают на 53,04%. Синтетические результаты детекторов не означают подтверждённого реального раннего предупреждения.

Отдельный стратифицированный национальный опыт на **114 МО / 120 рядах** имеет другую маску и нормирование. Его MAE 679,75 против 1707,22 не смешивается с пилотом выше. [Отдельный протокол](runs/R10_equal_information_h12_20261006/README.md).

## Как устроено исследование

1. Проверить календарь, полноту ряда и происхождение данных.
2. Сравнить прогнозы на одинаковых ключах и доступной истории.
3. Проверить детекторы на разных формах шока и собственных бюджетах ошибок.
4. Разобрать реальные территории по официальным источникам, сохраняя неопределённость.

## Проверка без входных данных

Из корня репозитория:

```sh
make radar-selfcheck PYTHON=python3
```

Используется стандартная библиотека Python. Проверяется механизм сверки и защита эталонов; модели не обучаются, научные результаты этой командой не подтверждаются.

## Воспроизведение сохранённого пакета

Сначала получите точный архив пяти входов, описанный в [манифесте](../data/frozen/radar/bundle-manifest.json). Архив не включён в публичный клон. После подготовки входов, из корня репозитория:

```sh
uv venv --python 3.13 .venv-radar
uv pip install --python .venv-radar/bin/python -r repository-tools/requirements-science.txt
make radar PYTHON=.venv-radar/bin/python RADAR_BUNDLE=/absolute/path/to/radar-frozen-inputs-20261005.zip
```

Установка зависимостей может обращаться к сети. Сам `make radar` работает офлайн, без LLM и нового обучения Prophet: сохранённые прогнозы Prophet используются как проверяемый вход. Базовые прогнозы, банки детекторов и проверки пакета пересчитываются; это не запуск всех последующих исследований. Несовпадение входного SHA или отсутствие файла останавливает расчёт.

[Полная инструкция, входы и состав проверки](../repository-tools/RADAR_REPRODUCE.md) · [Окружения двух проектов](../docs/REPRODUCIBILITY.md).

Отдельные команды для новых обучений перечислены в корневом [Makefile](../Makefile). Например, `radar-h12-equal` выполняет 2160 обучений для опыта на 114 МО; это другая задача, чем аудит 720 пар национального пилота на 20 МО.
