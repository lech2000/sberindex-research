# H12: национальный рост, фиксированный benchmark

Проверено05.10.2026 на Mac:470строк национального ряда через официальный
SOWA API, SHA, точная маска73608 сохранённых R9-прогнозов. Национальный ряд
содержит94месяца декабрь2018–сентябрь2026, пять укрупнённых типов расходов,
номинальные млрд руб. В прогноз переносится только безразмерное отношение.
UTC-даты переведены в московский календарный месяц; иначе декабрь превращался
бы в ноябрь. [Источник и паспорт](data-passport.json).

До расчёта зафиксирован протокол: `y_origin × N_(origin−1)/N_(origin−13)`.
Одинаковый национальный фактор «Всего» для шести муниципальных категорий,
без обучения и подбора параметров. Lag1 primary; lag2/3 sensitivity,
лучший lag не выбирается. Targets июль–декабрь2024, origin2023.

## Проверки и пределы

73608 actual/last-value сверены с raw точно.220824 прогнозных значений
(все три lag) пересчитаны скалярно; изменения будущих municipal/national
значений не меняют прогноз до соответствующего cutoff. Исходные SHA,
код и протокол сохранены. Полное обучение Prophet не повторялось.

Данные имеют **сегодняшний vintage2026**, неизвестны исторические даты
доступности, задержки и ревизии. Тест изменения будущих значений этого
не устраняет. Lag1/2/3 — предположения. Ретроспективная выборка исходного
R9 сохранена, unseen holdout отсутствует. Prophet не получал национальный
ряд: сравнение показывает эффект новой информации и формулы вместе,
не превосходство алгоритма при одинаковой информации.

Старая категория-сезонная модель всё ещё не поддерживает h12. Новый
национальный benchmark отдельный; R9/R8 научно не закрываются этим run.
На портале проверено условие упоминания СберИндекса при копировании;
CC BY-SA именно для этого национального набора не подтверждена.
Полный raw локален; публичны паспорт и производные метрики с указанием источника.
