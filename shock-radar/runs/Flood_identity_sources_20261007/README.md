# Шесть районов: получены первичные акты преобразования

Проверено 07.10.2026: скачаны **шесть оригинальных законов, 52 страницы** с официального портала опубликования правовых актов. Получены паспорта источников с SHA256 PDF и датами опубликования из карточек портала. Полная историческая привязка пока не принята: законы о преобразовании сами по себе не подтверждают актуальные ОКТМО, границы и соответствие статистического ряда.

Вторичный список ошибочно обозначал Кетовский закон номером 5; официальная карточка указывает №2. PDF первой страницы подтверждает преобразование Кетовского района. Страница 10, статья 8, отдельно упоминает закон, устанавливающий границы нового муниципального образования. Этот фрагмент проверен визуально по оригиналу.

В используемом словаре шесть старых районов имеют territory_id 1336, 1339, 1342, 1343, 1350, 1352 и конечные годы 2022–2024. Записей их одноимённых преемников в этом файле не найдено. Поле `year_to` не заменяет акт о преобразовании и не подтверждает юридическую идентичность территории на дату паводка.

Следующий шаг для каждой территории: оригинальный акт и карта границ → официальный ОКТМО преемника, действовавший в 2024 году → сопоставление территории статистического ряда → отдельное решение о допустимости включения в паводковую когорту. До этого шесть новых сопоставлений не допускаются. Замороженный `Flood_legal_cohort_20261005` не переписан.

## Воспроизведение

В серверной среде с доступом к официальному порталу:

```sh
python3 repository-tools/official_municipal_laws.py fetch \
  --manifest shock-radar/runs/Flood_identity_sources_20261007/source-manifest.json \
  --out output/official-municipal-laws-20261007 --http
```

Повторная проверка тех же файлов без сети:

```sh
python3 repository-tools/official_municipal_laws.py verify \
  --manifest shock-radar/runs/Flood_identity_sources_20261007/source-manifest.json \
  --out output/official-municipal-laws-20261007
```

Загрузка выполнена через SSH `joe` и Incus `kb-forge` по публичному HTTP. HTTPS с Mac и сервера в момент проверки не отвечал. SHA защищает воспроизводимость снимка, но не является независимой цифровой подписью. Сканы распознаны локально Tesseract с русской моделью; OCR содержит ошибки, весь распознанный текст не прошёл визуальную сверку. Даты и номера выше взяты из первичных HTML-карточек, а не из OCR.

В [паспорте](source-manifest.json) исторический `available_at`, час и часовой пояс опубликования оставлены неизвестными. Эти акты помогают установить идентичность МО; они не добавляют независимый будущий тест, не подтверждают раннее предупреждение и не заменяют акты о зонах паводка. Исходные PDF, изображения страниц и модель OCR не опубликованы в составе проекта.
