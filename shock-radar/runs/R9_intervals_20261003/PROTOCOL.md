# R9: парные интервалы на завершённом ретроспективном запуске

Зафиксировано 03.10.2026 до расчёта интервалов; средние MAE ранее просмотрены (внутренний аудит). Новый независимый тест не заявляется. Вход — предсказания полного R9, SHA b9726b7971c55e5c9f32cdfe439694ffc96f66d7b0c180725a7ad2dff68afe44. 294570 общих строк, 222 исключены из исходной маски из-за insufficient_train: 6 при h3, 216 при h12. h=1/3/6/12 оцениваются отдельно.

Используем существующий `_cluster_bootstrap` из R8: 10000 выборок целевых месяцев с возвращением; сумма парных разностей абсолютных ошибок / число строк выбранных блоков. Положительная разность означает меньший MAE Prophet. Основной интервал — 95% percentile по шести месяцам, дополнительный — по МО (2000). Leave-one-month-out, веса МО и доли одинаковых ошибок — диагностические показатели. Не вычисляем p-value и не выбираем модель/горизонт/порог по этому результату.

F7b/MiMo Pro ревью приложено. Независимый оператор исправил ошибочный знак в ответе агента: positive = Prophet выигрывает. Не приняты предложения о нормировании основной MAE (смена estimand) и о монотонном выигрыше сезонной модели (сезонность в данном Prophet отключена). BCa при шести блоках не делает тест независимым; оставляем ранее зафиксированный percentile с явными ограничениями. Семантические self-check: знаки, неравные размеры блоков, воспроизводимость, отказ на дублях/нечислах/неверном календарном горизонте.

Без проверенного historical available_at и нового периода этот анализ не разрешает scientific PASS, будущую точность или раннее предупреждение. Завершённый Prophet повторно не обучаем.
