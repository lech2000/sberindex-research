# R8 — итоговая научная приёмка, 29.09.2026

**Исследование завершено с отрицательным/неопределённым для внедрения
результатом; научный `PASS` не заявлен.** Это закрытие работы R8 с явно
ограниченным выводом, а не подтверждение исторического as-of прогноза,
раннего предупреждения или готовности открыть R9 на тех же данных.
Машиночитаемое решение — `decision.json`, матрица абляций — `ablations.csv`
(копия по пути, заданному лестницей: `../R8/ablations.csv`).

На одной маске из **171 150** точек за шесть целевых месяцев 2024 года
независимое соединение по `(territory_id, category, origin, target, horizon)`
дало MAE: Prophet **731,386**, last-available **880,213**, Chronos-T5-tiny
**939,062**, сезонный baseline **1280,420**. Строгий контроль ключей,
фактических значений и конечности прогнозов выполнен
`shock-radar/src/r8_monthblock_compare.py`; результат — в `monthblock/`.
Chronos не выиграл на этой маске. Разница абсолютных ошибок относительно
Prophet равна −207,675 в соглашении «положительное = выигрыш Chronos»;
95% интервал по шести целевым месяцам `[−516,664; +33,697]` включает ноль.

Точечный выигрыш Prophet над last-available — **148,827**, однако точное
перечисление всех `6^6` месячных bootstrap-выборок даёт интервал
`[−20,512; +365,449]`. Сентябрь 2024 у Prophet хуже простого baseline;
доля декабрьского выигрыша велика. Переносимость на будущие месяцы не
установлена. Результат является **разведочным**: эти данные уже изучались
до выбора модели и не составляют новый закрытый тест.

Новостной аудит оставил **0 из 64** событий с доказанной доступностью до
cutoff 2024 года. Поэтому news-only и news-enabled — `NA`, а не нулевой
эффект. 22 тематических/географических флага сохранены в аудите; их разбор
не создаст исторический `available_at`. Календарный бустинг ухудшил MAE
относительно бустинга без календаря (1000,794 против 961,104). Перемешанные
обучающие target дали MAE 944,094 — лучше неперемешанного бустинга, поэтому
утверждение о пользе бустинга снято. Oracle с будущим target исключён как
утечка. Локальные future-mutation контроли бустинга и Chronos прошли;
синтетические тесты новостного фильтра прошли, но реальный news-effect
проверить невозможно.

`lag_sensitivity.json` проверяет последнее **точно наблюдавшееся** значение
при предположенных лагах 1/2/3 месяца. Сохранённый baseline лага 2
совпал с исходной панелью в 171 150/171 150 строках. На общей маске
171 042 строк MAE для лагов 1/2/3: **853,339 / 879,510 / 842,957**.
Это только диагностика baseline: Prophet и Chronos при лагах 1 и 3 не
переобучались. Исторический момент публикации и версии расходов не
подтверждены; двухмесячный лаг — допущение. Следовательно, нельзя
называть расчёт историческим as-of прогнозом.

## Воспроизведение

Исходные прогнозы, метрики, аудит, манифест, версия весов и seed сохранены
в `../R8_prophet_full_20260927/` и `../R8_tsfm_deterministic_20260928/`.
Проверка общей маски и интервалы:

```bash
python3 shock-radar/src/r8_monthblock_compare.py \
  --prophet-run shock-radar/runs/R8_prophet_full_20260927 \
  --tsfm-run shock-radar/runs/R8_tsfm_deterministic_20260928 \
  --outdir /tmp/r8-monthblock-recheck --n-bootstrap 10000 --seed 20260928
```

Для лагов передайте сырой `8_consumption.parquet` с SHA-256
`9833ddaaee7b2a182ed4cceeed16469031700ea87d508bd976150c6770ef8a61`:

```bash
python3 shock-radar/src/r8_lag_sensitivity.py \
  --raw /path/to/8_consumption.parquet \
  --paired shock-radar/runs/R8_prophet_full_20260927/predictions.parquet \
  --output /tmp/r8-lag-recheck.json
python3 shock-radar/src/r8_closeout.py \
  --out shock-radar/runs/R8_closeout_20260929
```

Источники входов и SHA-256 зафиксированы в `decision.json`, а локальные
контроли воспроизводятся через `r8_tsfm_paired.py --self-check`,
`r8_monthblock_compare.py --self-check` и `r8_news_audit.py --self-check`.
Новый R9 допустим только с независимым временным holdout и подтверждённым
историческим vintage. Никакое число этого архива не является доказательством
раннего предупреждения.
