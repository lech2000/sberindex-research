## Реестр

Шесть событий: три муниципальных описания паводка, три национальных решения ЦБ. Источники и хеши — registry.json. МЧС документирует Орск 6 апреля; областной сводный прогноз 10 апреля перечисляет Оренбург и Новотроицк. Точный день начала экономического изменения не задан. Решения ЦБ опубликованы 26 июля / 13 сентября / 25 октября 2024 в 13:30 МСК: 18 / 19 / 21%. Решение национального уровня не размножается в независимые муниципальные события.

Поле first_seen фиксирует сегодняшнюю загрузку. Published date/time официальной страницы хранится отдельно; available_at и vintage остаются null, пока нет исторической проверки. Реестр пригоден для ретроспективных описаний; он не доказывает пригодность полного сегодняшнего текста в исторической прогнозной модели и не измеряет прирост от новостей.

## Детекторы

Использованы неизменные параметры R7_v2: D01 k=2,5; D02 delta=0,1/lambda=0,4; D03 tau=0,3 и strict log support. Обучающая калибровка заканчивается до марта 2024. Сигнал — реальная смежная месячная динамика last-value, без единого инжекта: 287 268 строк, 12 744 ряда. Cooldown 3, затем месячный лимит 24 (primary) / 96 (exploratory sensitivity).

Это лимиты всех выбранных тревог, не число ложных тревог. Полного истинного экономического реестра нет: precision, recall, false-alarm count получают NA. Алгоритмы и их пороги уже изучались на синтетике; эти три заранее предложенных примера не являются независимым тестом. Результат описательной проверки отрицательный для обнаружения изменений апреля–мая этих МО.

## Воспроизведение

```bash
python shock-radar/src/official_event_sources.py --outdir <NEW-intake-directory>
python shock-radar/src/official_cases_audit.py --self-check
python shock-radar/src/official_cases_audit.py --raw <frozen-8_consumption.parquet> --dictionary data/raw/sberindex-data-sense-2025/municipal_dictionary.parquet --atlas economic-atlas/data/panel_v1.parquet --assignments economic-atlas/runs/A6_v2/assignments.parquet --predictions <audited-R9-predictions.parquet> --events <NEW-intake-directory>/registry.json --threshold-manifest shock-radar/runs/R7_v2/manifest.json --outdir <NEW-case-run>
```

Загрузчик использует системный curl с включённой TLS-проверкой; текущий HTML при повторе может иметь новый SHA. Исторические scientific inputs сверяются по замороженным SHA. Сигнал и все выбранные тревоги находятся в локальных Parquet; публичные metrics содержат источники, точные значения трёх историй и их совпадения с тревогами.
