# D01-MV: общий бюджет банка после добавления Stouffer/GLR

Проверено05.10.2026 на Mac: original implementation, замороженный протокол,
20 новых synthetic seed, два noise family,4000 событий на ячейку.
Базовый банк:max/energy/Mahalanobis; расширенный:+Stouffer-down,
Stouffer-two-sided и trailing1/2/3 GLR. Банк — максимум оценок,
нормированных на q97 каждого канала из отдельной calibration sample.
Порог **всего банка**, а не отдельного канала, также получает свой
calibration sample. Это многомерное расширение; прежние D01/D02/D03
на одномерном сигнале остаются самостоятельными.

Первый режим: независимая калибровка target3%; реализованный test null FA
Gaussian2,848%/2,953%, t5:2,962%/3,136% (base/extended).
Второй режим: явная ретроспективная ROC-сверка при ровно3% реализованных
TEST null тревог каждого **полного банка**,180000 null-точек на family.
TESTnull не называется независимой калибровкой. Проверка future mutation
выполнена для обеих совместных оценок. Нулевой будущий сдвиг не используется.

Primary amplitude4, t5, matched total null3%:

| Форма синтетического сдвига | Base recall | Extended recall | Разность, п.п. |
|---|---:|---:|---:|
| Общее снижение |70,20%|94,25%|+24,05|
| Общий рост |69,575%|91,625%|+22,05|
| Постепенное общее снижение |44,525%|72,40%|+27,875|
| Разнонаправленный |91,65%|71,30%|−20,35|
| Разреженное снижение |95,725%|71,70%|−24,025|

CI95 gain ramp по20seed:[26,65;29,15]п.п.; opposed:[−21,625;−18,925]п.п.
Все amplitude2/4/6, формы, Gaussian/t5 и оба calibration режима сохранены.
Расширение помогает согласованным направлениям, но забирает общий
бюджет у разреженных и разнонаправленных событий. **Универсальное
улучшение не получено; включать расширенный банк как победителя нельзя.**
Это результат о компромиссе при одинаковой стоимости false alarms.

Нет real economic ground truth и оценки раннего предупреждения.
Полные4000 события в каждом seed-block сравнении не являются4000
независимыми реальными кризисами. Source labels и параметры изучались,
synthetic test seed отличны от calibration; научный PASS не выдан.
Legacy одномерный банк не изменён. Для real общего банка надо отдельно
заморозить24 selected alerts/month и проверить официальные события;
selected alert budget не приравнивать к реальным false alarms.
