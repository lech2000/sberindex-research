Последние шесть месяцев панели, июль–декабрь 2024, являются **целями**. Для горизонта `h` точка старта равна `target−h` календарных месяцев; все входы модели не позже неё. `last_value` берёт значение строго в точке старта, `seasonal_naive` — в `target−12`, `train_mean` — среднее доступных наблюдений до точки старта. Если старт или сезонное значение отсутствует, строка исключается из **общей** маски трёх методов, не заменяется соседним месяцем. MAE — среднее абсолютной ошибки на одинаковых парах `(МО, категория, старт, цель)`.

При `h=12` старт и сезонная точка совпадают, поэтому две первые колонки прогноза математически одинаковы; это не независимое подтверждение качества. Маски и знаменатели различаются между горизонтами, так что сравнивать MAE разных `h` как эффект метода нельзя. Единственное честное сравнение методов — внутри строки таблицы на общей маске.
