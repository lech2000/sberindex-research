# Данные исследований

Здесь находятся паспорта источников, манифесты, часть открытых таблиц и загрузчики. Код репозитория открыт; **публичный клон не содержит полного комплекта входов для всех расчётов**.

## Что опубликовано и что нужно получить отдельно

| Материалы | Где искать | Доступность |
| --- | --- | --- |
| Источники, единицы, схемы и SHA | [Каталог](DATA_CATALOG.md), [manifest.json](manifest.json), [schema-report.json](schema-report.json) | В Git; датированные статусы каталога описывают проверенный рабочий снимок |
| Часть таблиц БДМО и производных данных | [БДМО Точно](external/tochno_bdmo_20250918/README.md), [curated](curated/) | В Git; лицензия и происхождение названы у набора |
| Сырые расходы СберИндекса и национальные снимки | Манифесты проектов и загрузчики `data/*.sh`, `data/*.py` | Не входят в текущий публичный клон |
| Сохранённые прогнозы и словарь для базового повтора Радара | [Манифест входов](frozen/radar/manifest.json), [манифест архивного комплекта](frozen/radar/bundle-manifest.json) | Пять точных файлов нужно получить отдельно; владельческий ZIP не опубликован |
| Дополнительные входы Атласа | [Замороженные входы](../economic-atlas/frozen_inputs.json), [паспорт панели](../economic-atlas/DATA_PASSPORT_RELEASE_2026-10-05.md) | Наличие каждого файла и его SHA проверяется перед повтором |

`downloaded_verified` в историческом каталоге означает загрузку и проверку в рабочем окружении автора, а не наличие файла в свежем клоне. Новый текущий выпуск источника может отличаться от зафиксированного: его нельзя молча подставлять в прежний эксперимент.

## Загрузка открытых источников

Команды выполняются из **корня этого репозитория**, не из `ai_OS2`. Загрузчики сохраняют данные отдельно от опубликованных результатов. Это сетевые операции, не часть офлайн-воспроизведения. Для пакета Data Sense нужны Bash, `curl`, `jq`, `openssl` и `awk`; установка Python-зависимостей эти программы не устанавливает.

```sh
# Публичный пакет Data Sense 2025
bash data/download_sberindex_2025.sh
```

[Загрузчик сетки населения НИУ ВШЭ](download_hse_population_grid.sh) сохранён как рецепт авторского окружения. Он сочетает GNU-опции `dd`/`truncate` с BSD-вызовом `stat`; перед запуском нужно проверить эти утилиты. Универсальная работа этого рецепта на чистых macOS и Linux не подтверждена.

Для текущих дашбордов и проверки схем сначала создайте отдельное окружение:

```sh
uv venv --python 3.13 .venv-data
uv pip install --python .venv-data/bin/python -r requirements.txt
.venv-data/bin/python data/download_sberindex_current.py
.venv-data/bin/python data/prepare_supplementary_data.py
.venv-data/bin/python data/build_catalog.py
```

Последние две команды обрабатывают уже имеющиеся локальные источники. Если исходных файлов нет, загрузка дашбордов не заменяет их. Проверка схем и пересборка каталога не является пересчётом всех научных результатов.

## Точный повтор и обновлённые данные

Для старого опыта нужны его точные файлы и SHA. [Воспроизведение](../docs/REPRODUCIBILITY.md) перечисляет окружения и зависимости; [инструкция Радара](../repository-tools/RADAR_REPRODUCE.md) описывает проверку архивного комплекта.

Обновлённый или расширенный выпуск — новый вход: сначала сверяются схема, ключи территорий, единицы, календарь, пропуски и изменившиеся значения. Прежние данные и результаты сохраняются. [Загрузка собственной таблицы и сравнение выпусков](../docs/USER_DATASET_GUIDE_RU.md).
