## Главные находки

**Перестройка расходов видна во всей панели Атласа.** В 2023–2024 доля маркетплейсов выросла во всех **1896 МО**; медианное изменение — **+4,173 п.п.** В **1803 МО** продовольственная доля снизилась при росте номинального показателя. Это различие между структурой и уровнем расходов, а не измерение благосостояния. [Расчёт](economic-atlas/runs/consumption_restructuring_20261005/README.md) · [Арифметический аудит 08.10](https://github.com/lech2000/sberindex-research/blob/cf08fd779cbf12a8df15a95066de1cdb22800806/docs/evidence/submission-numeric-audit-20261008/atlas/REPORT.md).

**Простой национальный фактор полезен для длинного прогноза.** В пилоте на **20 МО, 120 рядах и 720 парных прогнозах** за июль–декабрь 2024 модель с прошлогодним национальным изменением дала **MAE 598,09 против 946,14** у Prophet с национальным регрессором: ошибка ниже на **36,79%**. На маркетплейсах модель хуже на 53,04%. MAE — средняя абсолютная ошибка; меньше означает лучше. Это ретроспективный пилот горизонта 12 месяцев. [Все модели и протокол](shock-radar/runs/National_equal_information_20261006/README.md) · [Арифметический аудит 08.10](https://github.com/lech2000/sberindex-research/blob/cf08fd779cbf12a8df15a95066de1cdb22800806/docs/evidence/submission-numeric-audit-20261008/radar/REPORT.json).

**Местные отклонения можно проверить на разных правилах сопоставления.** Выделены **25 историй**; **9** сохраняются не менее чем в **80% из 45** вариантов поиска. Это кандидаты для разбора, а не подтверждённые реальные шоки: число сигналов само по себе не доказывает их редкость. [Проверка чувствительности](economic-atlas/runs/Consumer_closeout_20261006/README.md).

**Вклад соседей отделён от общей прогнозной поправки.** Интеграция Атласа и Радара снижает MAE общих расходов на **2,69% / 3,79%** для горизонтов 1 / 3 месяца. Добавка именно соседей составляет **0,13% / 0,60%**, и её интервалы включают ноль. [Разделение эффектов](economic-atlas/runs/Consumer_mechanisms_20261007/README.md).

Результаты относятся к уже изученным данным. Исторические даты доступности источников и новый независимый временной тест пока не подтверждены; причинность и реальное раннее предупреждение не заявляются. Границы каждого опыта находятся рядом с его результатами.

## Проверка без исходных данных

Из корня клона, при установленных Python и Make:

```sh
make radar-selfcheck PYTHON=python3
```

Команда проверяет механизм сверки и защиту эталонов, используя стандартную библиотеку Python. Она не обучает модели и не подтверждает научные выводы.

Полный повтор требует точных входных файлов. Публичный клон содержит код, отчёты, манифесты и часть таблиц, но не все сырые наборы и сохранённые прогнозы. [Что нужно получить отдельно](data/README.md) · [Воспроизведение Радара](repository-tools/RADAR_REPRODUCE.md).
