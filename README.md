## Какие данные используются

Основные муниципальные расходы — январь 2023 — декабрь 2024: пять отдельных
категорий и агрегат «Все категории». Рабочая панель Атласа — **1 896 территорий,
273 024 записи**; многокатегорийный эксперимент D04 использует отдельную
полную маску **2 016 МО**. Маски разных исследований не смешиваются.

Атлас кластеризует **пять долей расходов**. Население, миграция, зарплаты,
занятость, бюджеты и справочники служат контекстом и отдельными проверками.
Пять категорий не исчерпывают агрегат; агрегат не прибавляется к ним.
Национальный R10 использует отдельный ряд: **94 месяца, декабрь 2018 —
сентябрь 2026**, из текущего выпуска данных.

Происхождение, единицы, ограничения и SHA: [паспорт Атласа](https://github.com/lech2000/sberindex-research/blob/953ac80115bacd9ba0315b33d78c499b5332d5a7/economic-atlas/DATA_PASSPORT_RELEASE_2026-10-05.md),
[паспорт национального ряда](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/shock-radar/runs/R10_national_h12_20261005/data-passport.json),
[общий каталог](data/DATA_CATALOG.md). Сырые внешние файлы новых пакетов
сохранены отдельно; в Git опубликованы код, протоколы и производные результаты.

## Что получил Радар

**Сезонные прогнозы R9.** На общей маске **218 202 прогнозов** за июль–декабрь
2024 Profile SES дал следующую среднюю абсолютную ошибку (MAE; меньше — лучше).
Каждый горизонт сравнивается на своей общей маске моделей.

| Горизонт | Profile SES | Простая категорийная сезонность | Growth3 |
|---|---:|---:|---:|
| 1 месяц | 299,96 | 307,10 | 339,20 |
| 3 месяца | 408,88 | 448,17 | 470,62 |
| 6 месяцев | 591,97 | 617,98 | 665,41 |

Это исследовательское сравнение уже просмотренного периода. На раннем окне
Profile SES проигрывает некоторым простым вариантам; интервалы преимущества
над категорийной сезонностью на h1/h3 пересекают ноль. Полные таблицы и
сравнение Prophet при общей информации — в [отчёте R9](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/shock-radar/runs/R9_strong_baselines_20261004/README.md).

**Национальный прогноз R10, горизонт 12 месяцев.** На **73 608 общих строках**
фиксированный национальный рост с lag1 дал MAE **651,27**, сохранённый Prophet —
**1 109,52**, последнее значение — **1 288,25**. На маркетплейсах новый прогноз
хуже Prophet на **50,33%**. Национальный ряд взят из выпуска 2026; историческая
доступность не подтверждена, а Prophet не получал тот же внешний ряд. Поэтому
это не доказательство превосходства алгоритма при одинаковой информации.
[Результаты по всем категориям и месяцам](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/shock-radar/runs/R10_national_h12_20261005/README.md).

**Детекторы D04/D05.** Многокатегорийные оценки проверены на синтетике и
описательных реальных примерах. Добавление Stouffer/GLR при одном бюджете
тревог улучшает обнаружение согласованных сдвигов и ухудшает разреженные
и разнонаправленные. Универсального улучшения нет; реальные precision/recall
и частота ложных тревог не установлены. [D04](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/shock-radar/runs/D04_multicategory_20261004/README.md),
[D05: весь банк при общем бюджете](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/shock-radar/runs/D05_joint_bank_20261005/README.md).

**Паводковая когорта.** Строго сопоставлена **1 из 7** территорий курганского
акта; для шести переход «район → округ» требует официального подтверждения.
Режим ЧС не приравнивается к доказанному затоплению. Проверка остаётся
частичной, причинный эффект не оценён. [Паспорта и ограничения](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/shock-radar/runs/Flood_legal_cohort_20261005/README.md).

По [квитанции 05.10](https://github.com/lech2000/sberindex-research/blob/c99fdc3b012c09995e99c49668388e64ed466209/docs/RADAR_STATUS_CLARIFICATION_20261005.md),
R8 завершён 29.09 как **INCONCLUSIVE / NO SCIENTIFIC PASS**. Независимая
научная проверка R9 остаётся открытой.

## Запуск

На проверенном научном runtime используется Python 3.14.5. Виртуальная среда:

```sh
uv venv --python 3.14.5
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python repository-tools/validate_repository.py
.venv/bin/python repository-tools/reproduce.py --self-check
```

Новые результаты пишутся в `output/reproduced/`; архивные `runs/` сохраняются.
Для полного расчёта A5/R7 сначала скачайте публичный пакет организаторов:

```sh
bash data/download_sberindex_2025.sh
.venv/bin/python repository-tools/reproduce.py --stage all
```

Подробные команды и пределы повторяемости — [REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md).
Ни GitHub, ни ФиксАР, ни LLM не нужны для научных самопроверок и расчётов.
Дополнительные TSFM-модели требуют собственных зависимостей и весов.

Шаблоны презентации можно открыть локально:

```sh
python3 -m http.server 8765
```

[Атлас](http://localhost:8765/presentation/economic-atlas/landing/),
[Радар](http://localhost:8765/presentation/shock-radar/landing/).
Карта показывает географический фон OSM 2021, а не результаты кластеризации или прогнозов.
