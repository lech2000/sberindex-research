## Какие данные используются

Основные муниципальные расходы — январь 2023 — декабрь 2024: пять отдельных
категорий и агрегат «Все категории». Рабочая панель Атласа — **1 896 территорий,
273 024 записи**; многокатегорийный эксперимент D04 использует отдельную
полную маску **2 016 МО**. Маски разных исследований не смешиваются.

Атлас кластеризует **пять долей расходов**. Население, миграция, зарплаты,
занятость, бюджеты и справочники служат контекстом и отдельными проверками.
Пять категорий не исчерпывают агрегат; агрегат не прибавляется к ним.
Национальный R10 использует отдельный ряд: **94 месяца, декабрь 2018 —
сентябрь 2026**, из текущего выпуска данных.

Происхождение, единицы, ограничения и SHA: [паспорт Атласа](economic-atlas/DATA_PASSPORT_RELEASE_2026-10-05.md),
[паспорт национального ряда](shock-radar/runs/R10_national_h12_20261005/data-passport.json),
[общий каталог](data/DATA_CATALOG.md). Сырые внешние файлы новых пакетов
сохранены отдельно; в Git опубликованы код, протоколы и производные результаты.

## Потребительская перестройка и совместная проверка

[Новое исследование и прогнозная проверка](economic-atlas/runs/Consumption_restructuring_forecast_20261005_v2/README.md):
по данным 2023 зафиксированы сопоставления для **1 539 из 1 896** территорий.
Найдены **25 устойчивых необычных изменений маркетплейсов** во втором полугодии
2024; только два сопровождаются устойчивым отклонением ещё одной доли.
В исходном варианте со средней поправкой добавка отклонений **не улучшила прогноз**: для общих расходов на
месяц MAE выросла с **686,4 до 1 189,1**, на горизонтах 3 и 6 месяцев тоже хуже.
Все модели пересчитаны на одной маске; эти числа не равны прежней маске R9.
2024 уже просмотрен, новый независимый тест не заявлен. Доступна
[автономная карта с шестью историями](economic-atlas/site/consumption-restructuring-20261005/index.html),
поиском всех территорий, категориями, соседями и фактом против прогноза.

[Отдельный численный пересчёт 6 октября](economic-atlas/runs/Consumer_validation_20261006/README.md)
подтвердил все ошибки моделей, соседства и числа карты. Основной проигрыш
возникает уже при переносе средней прошлой ошибки; добавление отклонений
немного уменьшает её ошибку, но не обгоняет исходный Profile SES.
Это проверка реализации на тех же данных, а не новый независимый тест.

[Описательная проверка гипотез PDF](economic-atlas/runs/consumption_restructuring_20261005/README.md)
на фиксированной панели 1 896 территорий: доля маркетплейсов выросла во всех
территориях; медианное изменение +4,173 процентного пункта. В 1 803 территориях
доля продовольствия снизилась при росте его номинального показателя. Изменение
долей не доказывает обеднение, панику или отток денег. Код и полный JSON сохранены.

[Совместная проверка Атласа и Радара](economic-atlas/runs/Atlas_Radar_joint_20261005/README.md)
использует профили 2023 и сезонные прогнозы для Орска, Кургана и Ишима.
Во всех трёх городах апрельские общие расходы выше прогноза; глубокий общий
спад не подтверждён. Описательное отставание маркетплейсов от сопоставлений
требует проверки на других событиях. Три города принадлежат одному профилю,
поэтому различие реакции между группами на них оценить нельзя. Причинный
эффект паводка и научный PASS не установлены.

## Что получил Радар

**Сезонные прогнозы R9.** На общей маске **218 202 прогнозов** за июль–декабрь
2024 Profile SES дал следующую среднюю абсолютную ошибку (MAE; меньше — лучше).
Каждый горизонт сравнивается на своей общей маске моделей.

| Горизонт | Profile SES | Простая категорийная сезонность | Growth3 |
|---|---:|---:|---:|
| 1 месяц | 299,96 | 307,10 | 339,20 |
| 3 месяца | 408,88 | 448,17 | 470,62 |
| 6 месяцев | 591,97 | 617,98 | 665,41 |

Это исследовательское сравнение уже просмотренного периода. На раннем окне
Profile SES проигрывает некоторым простым вариантам; интервалы преимущества
над категорийной сезонностью на h1/h3 пересекают ноль. Полные таблицы и
сравнение Prophet при общей информации — в [отчёте R9](shock-radar/runs/R9_strong_baselines_20261004/README.md).

**Национальный прогноз R10, горизонт 12 месяцев.** На **73 608 общих строках**
фиксированный национальный рост с lag1 дал MAE **651,27**, сохранённый Prophet —
**1 109,52**, последнее значение — **1 288,25**. На маркетплейсах новый прогноз
хуже Prophet на **50,33%**. Национальный ряд взят из выпуска 2026; историческая
доступность не подтверждена, а Prophet не получал тот же внешний ряд. Поэтому
это не доказательство превосходства алгоритма при одинаковой информации.
[Результаты по всем категориям и месяцам](shock-radar/runs/R10_national_h12_20261005/README.md).

**Детекторы D04/D05.** Многокатегорийные оценки проверены на синтетике и
описательных реальных примерах. Добавление Stouffer/GLR при одном бюджете
тревог улучшает обнаружение согласованных сдвигов и ухудшает разреженные
и разнонаправленные. Универсального улучшения нет; реальные precision/recall
и частота ложных тревог не установлены. [D04](shock-radar/runs/D04_multicategory_20261004/README.md),
[D05: весь банк при общем бюджете](shock-radar/runs/D05_joint_bank_20261005/README.md).

**Паводковая когорта.** Строго сопоставлена **1 из 7** территорий курганского
акта; для шести переход «район → округ» требует официального подтверждения.
Режим ЧС не приравнивается к доказанному затоплению. Проверка остаётся
частичной, причинный эффект не оценён. [Паспорта и ограничения](shock-radar/runs/Flood_legal_cohort_20261005/README.md).

По [квитанции 05.10](docs/RADAR_STATUS_CLARIFICATION_20261005.md),
R8 завершён 29.09 как **INCONCLUSIVE / NO SCIENTIFIC PASS**. Независимая
научная проверка R9 остаётся открытой.

## Запуск

На проверенном научном runtime используется Python 3.14.5. Виртуальная среда:

```sh
uv venv --python 3.14.5
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python repository-tools/validate_repository.py
.venv/bin/python repository-tools/reproduce.py --self-check
```

Новые результаты пишутся в `output/reproduced/`; архивные `runs/` сохраняются.
Для полного расчёта A5/R7 сначала скачайте публичный пакет организаторов:
